---
name: Game ordering preference
description: User preference for placing newly added games in the catalog
---

New games do not need to be placed chronologically or alphabetically. Choose the catalog position that best fits the current layout or user request.

**Why:** The user explicitly removed the previous ordering constraint.

**How to apply:** When adding a game to the Games library and Shop, do not spend effort preserving chronological or alphabetical order unless the user specifically asks for it.
