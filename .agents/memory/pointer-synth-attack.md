---
name: Pointer synth attack
description: Pointer-drag keyboard notes need a fast attack when the instrument has a slow pad swell.
---

Pointer-triggered notes should use a short attack so drag-across notes become audible before the pointer leaves the key; held computer-keyboard notes can retain the slower musical attack.

**Why:** A slow supersaw pad attack sounds good when a key is held, but drag interactions release each key before the swell reaches full volume, making the drag sound unexpectedly quiet.

**How to apply:** Keep pointer and physical-keyboard note triggering distinct when tuning envelopes for the Keyboard Studio.
